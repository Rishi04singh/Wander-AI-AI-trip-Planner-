## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Rishi04singh/Wander-AI-AI-trip-Planner-.git
```

### Move into Project

```bash
cd Wander-AI-AI-trip-Planner-
```

### Install Dependencies

```bash
npm install
```

### Run the Project

```bash
npm run dev
```
